# AlphaZero 网络容量与 Greedy 对照

两组均新增训练 1,000 局，seed=11，400 次 MCTS 模拟，Greedy 对手比例固定 .6，规则为 freestyle。
测试使用验证集选出的 best.pt；每色 100 局，测试种子 800000/900000，与验证种子分离。
未完成阶段只显示状态，不把第 0 局验证成绩当成最终测试。

| 实验 | 通道 / 参数量 | 状态 | Greedy 黑胜率 | Greedy 白胜率 |
|---|---|---|---:|---:|
| az_width64_fixed | 64/64/64 · 94,935 | complete 1000 / 1000 | 81.0% | 61.0% |
| az_width128_fixed | 64/64/128 · 132,055 | complete 1000 / 1000 | 82.0% | 62.0% |

## 最终测试明细

| 实验 | 执子 | 胜 / 和 / 负 | 胜率（95% Wilson 区间） | score | 验证选中局数 |
|---|---|---|---|---:|---:|
| az_width64_fixed | 黑 | 81 / 5 / 14 | 81.0% (50.0–95.0%) | 0.835 | 0 |
| az_width64_fixed | 白 | 61 / 5 / 34 | 61.0% (50.0–95.0%) | 0.635 | 0 |
| az_width128_fixed | 黑 | 82 / 5 / 13 | 82.0% (50.0–95.0%) | 0.845 | 0 |
| az_width128_fixed | 白 | 62 / 5 / 33 | 62.0% (50.0–95.0%) | 0.645 | 0 |

64/64/128 减 64/64/64：黑棋胜率差 +1.0 个百分点，白棋 +1.0 个百分点，两色平均 +1.0 个百分点。
这只是 seed=11 的单次容量对照；不能据此断言加宽网络稳定更强或更弱。两组同源暖启动，新增训练预算相同。
best.pt 可能来自暖启动后的第 0 局验证；表中的选中局数用于区分训练终点与实际测试权重。score=胜率+0.5×和率。
