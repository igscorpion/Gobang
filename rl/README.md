## 算法定位

| 算法 | 作用 |
|---|---|
| Random / Greedy | 随机与棋型启发式基准 |
| Minimax | Negamax + Alpha-Beta，启发式限制分支，并非完备搜索 |
| Pure MCTS | UCT + 随机 rollout，没有神经网络 |
| 线性 Q-Learning | 棋型特征的线性动作价值，保留上游实现 |
| DQN | CNN 动作价值，四通道与混合对手重训 |
| A2C（本地新增） | 同步 8 环境/5-step Actor-Critic，与 DQN4 作四通道配对对照 |
| A2C＋战术规则 | `a2c4_tactical` 复用原 A2C 权重，加入规则约束、战术候选与有限 VCF；属于独立推理增强版 |
| AlphaZero-lite | CNN 策略/价值双头 + PUCT 搜索 |

这份上游不包含 REINFORCE/A2C；此前独立多算法实验位于旧目录，不混入本轮对照。本地新增的 A2C 已于 2026-10-15 完成原方案三个种子各 30,000 局训练、合计 14,400 局验证与 1,200 局冻结测试，见 [A2C4 方案与结果](../docs/a2c-control.md) 及 [对照报告](../runs/production/a2c_dqn_comparison.md)。网页选项 `a2c4` 使用 seed22 第 19,000 局的 `best.pt`，只按验证 Greedy 黑白平均 score=0.0125 选出，未用测试选模型。

环境内部 `1/-1/0` 表示黑/白/空。`get_state()` 返回当前玩家视角：己方 `1`、对手 `-1`。动作是 `row * 9 + col`；`step` 的终局奖励相对刚落子玩家，胜为 +1，其他为 0。

`needs_last_move=True` 的 Agent 接收 `(相对棋盘, 对手上一步动作或 None)`。共用 `rl/environment/state.py` 构造四通道：己方、对手、对手上一步、是否先手（整平面 1 或 0）。训练历史对手、网页与评估均遵守此约定。

## AlphaZero

三层 3×3 卷积输出 64、64、128 通道，分别接 ReLU。策略头以 1×1 卷积降至 2 通道，再输出 81 个 logits；价值头降至 1 通道，再接 81→64→1 与 Tanh。总参数 132,055。

旧 64³ 网络 94,935 参数。暖启动直接复制同形张量；第三层和两个 1×1 头复制旧切片，新增切片随机初始化。形状与来源 SHA-256 写入 `transfer.json`，优化器重建。迁移后预测可能暂时下降，不能假设完全保留旧棋力。

PUCT 每步默认 400 次模拟，c_puct=1.4；训练根加入 Dirichlet 噪声。记录 MCTS 访问分布与最终胜负，使用旋转/镜像 8 倍增强。策略交叉熵 + 价值 MSE + L2(1e-4)，每批最多 5 次更新，以 KL 早停并调节学习率。

Adam 初始学习率 .0005，每 2000 局减半；EMA=.999；回放池最多 40,000 个增强样本，批量 512。课程根据验证集对 greedy 的分色平均胜率调整比例，以 .1 为步长，目标 .1/.2/.4/.6；自对弈短局占比 ≥.8 会提高对手压力。短局比例只是诊断信号，不能单独证明坍塌。

`training.csv` 的 `recorded_positions` 表示增强前被记录的局面数：自对弈是整局手数，对 greedy 是网络自己的落子数，两者不能直接混算均长。

## DQN

输入默认四通道，卷积 32/64/64，接 256 隐层与 81 个 Q 值。旧三通道模型可按原结构加载；四通道训练从头开始。三通道消融使用己方/对手/空位。

训练器采用 Double DQN：online 在合法动作中选下一动作，target 估值；终局和无合法动作不 bootstrap。自对弈一步后视角换到对手，目标的未来价值取负；对固定/历史对手两步后回到自己视角，取正。两种经验通过显式 sign 混合。只记录学习者落子，对手回合不作为模仿样本。

Adam=3e-4、Huber loss、梯度裁剪 5、gamma=.99、batch=64、replay=30,000。每 4 条经验更新一次，target 每 200 次更新同步。ε 前 15,000 局由 1 降到 .05；每 1,000 局向历史池加一份网络，最多 4 份。

greedy 比例课程初始 .1；random 固定 .15；历史池可用时额外 .15，余量自对弈。这里只使用终局奖励，未叠加奖励塑形，以免污染通道消融。

## A2C

四通道输入、32/64/64 三层卷积和 FC256 共享主干，输出 81 维策略与单值价值头，共 1,405,042 参数。同步 8 环境各采集最多 5 个学习转移，每轮新鲜轨迹仅更新一次，不使用回放。Adam=3e-4、gamma=.99、价值损失系数 .5、熵系数 .01、梯度范数上限 5。自对弈视角交替的回报取负号，对固定或历史对手两手后回到学习者视角取正号；合法动作掩码、历史池和课程机制与 DQN4 对齐。

冻结测试每个种子对 Random/Greedy 分黑白各 100 局，均无和棋。三种子 Random 黑 / 白胜率为 98.00%±1.00 / 97.67%±1.53，Greedy 为 1.67%±2.89 / 0.33%±0.58（均值±样本标准差，标准差单位为百分点）。Greedy 棋力仍弱。DQN4 仅 seed11 完整：同种子 A2C 对 Random 黑 / 白高 23 / 31 个百分点，对 Greedy 差均为 0；其余 DQN4 种子保留空白。近似同容量与同课程机制不等于严格同计算预算，也不足以据此给出三种子算法排名。

## 评估与兼容

验证和测试分 random/greedy、黑/白四组，分别报告胜/和/负、胜率、score=胜率+.5×和率、Wilson 区间。选择 best 只用验证集 greedy 平均 score，最终测试使用独立固定种子与 best 权重。

`train_dqn.py`、`train_alphazero.py` 保留模块入口，统一采用显式参数；旧的 positional/infinite 参数不再适用。上游实验记录见 `docs/history/upstream-rl-README.md`，不可把其中成绩归给新模型。
