# rl 目录说明

强化学习核心，可脱离 Web 独立运行。本文件简要说明目录结构，并重点记录各模型的当前状态与阶段性结论。

## 目录结构

```text
rl/
├── environment/   9×9 五子棋环境（gomoku.py）
├── agents/        AI 实现：BaseAgent / Random / Greedy / QLearning / DQN / AlphaZero + registry
├── training/      训练脚本：train.py（通用循环）、train_dqn.py、train_alphazero.py
├── evaluation/    胜率评估（evaluate.py）
├── models/        训练产物：权重、检查点、累计局数元数据
└── demo_qlearning.py   Q-Learning 训练/评估演示
```

## 模型状态与结论

> 评测口径：AI 执黑、对手执白，各进行若干局对弈统计胜率。对照对手为 `random`（随机）与 `greedy`（手工贪心启发式）。

### RandomAgent —— 随机基准

随机落子。任何具备基本攻防能力的策略均可稳定取胜，因此各学习型算法最终均达到 **vs random ≈ 1.0**。它仅作为下限基准。

### GreedyAgent —— 贪心启发式基准（当前最强对手）

以 13 个手工特征（成五/活四/冲四/活三/眠三/活二，以及对方的对应威胁）结合手工权重对候选落子打分，兼具进攻与防守能力。

**定位**：它是**线性特征表达能力的上限**——本质是“手调的线性策略”，是该特征空间内的较优解。

### QLearningAgent —— 线性 Q-Learning

线性函数近似 Q-Learning：`Q(s,a) = w·φ(s,a)`，与 greedy 采用**同一套 13 个手工特征**，区别仅在于权重由学习获得还是人工设定。基于这一判断，该方向已暂告一段落——除非更换特征表示，否则继续投入的意义有限——它很难超越 greedy。

训练结果：

| 对手 | 胜率 |
| --- | --- |
| vs random | 1.00 |
| vs greedy | 0.00 |

**训练时长**：不足 1 小时。

**结论**：线性特征 + 学习，**上限约等于 greedy**（greedy 本身就是该特征空间的手调较优解）。这印证了：**要超越手工特征，必须由模型自行学习特征（神经网络），而非在学习同一套特征的权重。**

### DQNAgent —— 深度 Q 网络

3 通道 CNN 输出 81 维 Q 值，自对弈（negamax）+ 经验回放 + 目标网络。

| 对手 | 胜率 |
| --- | --- |
| vs random | 1.00 |
| vs greedy | 0.00 |

**训练时长**：不足 1 小时（自对弈）。

**判断**：仍需更充分的训练加以检验。

### AlphaZeroAgent —— AlphaZero-lite（当前主线，训练中）

MCTS（PUCT）+ 双头（策略/价值）网络，自对弈训练。已落地：**4 通道输入（己方/对手/对手上一步/是否先手）、8× 数据增强（旋转/镜像）、Dirichlet 噪声、L2 正则、按 KL 自适应调节学习率、400 次模拟/步、断点续训、无限训练**。

当前状态：**累计约 3600 局（训练约 5 小时），处于约 1.5 阶段**——模型已从随机落子中走出，学会了让棋子彼此聚集、向对手落子附近靠拢，但未掌握防守的要领，面对对手成线时不会在线上阻拦。现已发现模型在约4000局时不再成长，需将MCTS模拟次数提高后再继续训练

预期学习阶段：

```text
0 随机 → 1 聚集 → 2 防守 → 3 做活三/活四 → 4 双杀 → 5 战胜 greedy
```

对照已有公开实现（8×8 五连需 2000~3000 局、800 次模拟/步才可用），9×9 预计需 **5000~10000 局才能明显具备“堵截与做威胁”能力**，战胜 greedy 需更久。

## 训练与复现

- 棋盘 9×9、五连。
- 训练环境：Python 3.11 + GPU（RTX 3060，torch 2.14.1+cu132）。
- 训练入口：项目根目录双击 [训练AlphaZero.bat](../训练AlphaZero.bat)，或 `py -3.11 -m rl.training.train_alphazero`（无限训练，每 100 局存盘、每 1000 局评估）。
- 模型产物：`models/alphazero.pt`（AlphaZero 检查点）、`models/alphazero_meta.json`（累计局数）、`models/dqn.pt`、`models/q_learning.json`。
