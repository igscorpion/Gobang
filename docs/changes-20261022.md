# 本轮更新：容量探索、A2C实现与性能增强

分支：`A2C`；基线：`2711ccafd8ff44857ee4c8f594ccda40dbadcfb0`。

## 方法与实现

- AlphaZero第三层扩至128通道，保留原64层兼容和部分迁移，迁移来源写SHA，优化器重新建立；DQN增加行动方/上一步信息、合法masked Double DQN和零和视角目标。
- 新增同步8环境×5-step A2C。合法Categorical采样、终局回报、value/entropy损失、梯度裁剪；自对弈与固定对手转移分别处理回报符号，不使用陈旧回放动作伪装on-policy。
- 增加 `a2c4_tactical`，在同一原权重上加入直接成五、完整急防、双威胁及有限VCF；原纯A2C保持独立。
- 增加四/十通道、flat/residual表示对照；以AZ400合法动作标签CE预训练，再做A2C+0.1CE。新残差网络305,538参数，空间策略头、GAP价值头。
- 新 `guarded` 在可靠战术处理之外，普通局面面对完整合法动作集；注册为 `a2c_residual10_guarded`，明确Research10通道、CPU及冻结战术参数。
- 共用禁手规则、分色评估、验证选优、来源SHA、可恢复训练、完整策略冻结与独立重放审计。

## 训练历程与实验结论

| 阶段 | 观察 | 结论 |
|---|---|---|
| AZ容量单seed | 黑89%→94%，白69%→70%，白score不变 | 有小幅收益，不能证明扩容稳定解决瓶颈 |
| DQN四通道单seed | Random黑/白+8/+11个百分点，Greedy仍0/0 | 随机胜率改善不能代表战术能力突破 |
| 原A2C三seed | Random约98%，Greedy黑1.67%/白0.33% | 新更新公式并未自动解决攻防学习 |
| 旧权重战术增强 | 无新增训练，历史Greedy各格54%–59% | 推理知识有效，但收益与网络学习分开 |
| 专家/表示/结构 | 2×2存在有效组，也有RL最佳仍在0局 | 教师与空间/战术先验有帮助，效果非单调 |
| 去掉普通候选过筛 | 同权重开发白胜率42.5%→67.5%→70% | 强网络会受旧启发式限制，保护与筛选应区分 |
| 三seed最终guarded | 无禁手黑92%/白78.67%，禁手黑53%/白82.33% | 多个分组改善；禁手黑未超过旧增强58% |

开发与最终测试使用不同种子。完整结果采用各自验证选中的权重，不能把训练终点直接视为最优；共享教师数据与不同计算预算限制算法因果归因。

## 已排除的方向与未解决问题

- 同候选手工排序替换神经排序：开发总胜87→57，负局相同，全面替换不成立。
- 旧网络浅搜：depth3主要把失败变和棋，80局仅多赢1局；depth2和加宽候选效果更差。
- 只增加Greedy训练比例：旧纯策略内部最优仍在起点；60%局数仅提供约34.4%学习转移，强对手短局与稀疏反馈是可能限制。
- CE后纯A2C继续训练：部分组没有超过CE起点；旧弱策略的包装成绩曾掩盖纯策略不足。
- 新网络上的四种full-tactics-root搜索最高开发score .78125，低于同checkpoint guarded .89375且更耗时；value混合没有改善score。不外推所有搜索设计。
- 禁手黑方种子胜率42%–65%，均值53%、和率36%。合法掩码解决违规，不等于学会禁手分布下的进攻；规则迁移仍是短板。
- 残差参数少78.25%，纯网络估算MAC反而约4.12倍，不能按参数量宣传更快。

完整原因分析明确区分观察与推测，见 [研究总报告](../runs/a2c_research_20261020/final_report.md)。早期未完成DQN重复和AZ课程延长不填造成绩；AZ400禁手参考已取消本次开展，不再等待或补跑。

## 评估与验证

31项/6,200完整局独立审计通过：164,639合法步、81,164个Greedy/Random动作精确复现；3项操作重试前缀一致，只取首个完整accepted attempt，不混partial。审计未重新执行候选网络或证明搜索，边界保留。

展示模型按开发集预选seed11@30k，最终测试不选模；每seed每色100局Wilson95，跨训练seed样本SD。无A2C对AZ直接对弈结论。9×9和当前规则/开局范围不代表完整赛事棋力。
