## 对照设计

| 对照 | 控制变量 | 新增预算 |
|---|---|---:|
| DQN 3 通道 vs 4 通道 | 相同训练器、超参、混合对手策略、种子 11/22/33 | 6×30,000=180,000 局 |
| A2C4 vs DQN4（A2C 三种子已完成） | 相同四通道、近似同容量主干、同课程机制、种子 11/22/33；DQN4 目前仅 seed11 完整 | A2C 新增 3×30,000=90,000 局 |
| AZ 64/64/64 vs 64/64/128 | 同源暖启动、seed=11、greedy=.6、400 simulations | 2×1,000 局 |
| AZ fixed vs adaptive | 同一加宽 final.pt 起点，seed=22，双方重置 Adam，400 simulations | 2×1,000 局 |
| Greedy 同策略规则对照 | 冻结启发式、配对四手随机开局与种子 | 每规则 300 局 |
| AZ 同权重规则对照 | 验证选出的宽网络、400 simulations、配对四手开局 | 每规则 100 局 |

容量与课程分两步比较。DQN 三通道控制也包含正确的视角目标、合法动作掩码与 Double DQN，不能称为“完全复现上游训练器”。AZ 目前每组单种子，是探索性实验；DQN 三种子亦不足以保证稳健显著性。

A2C 的完整设计见 [A2C 四通道对照组](a2c-control.md)。它与 DQN4 比较学习方法；AlphaZero 作为含搜索和暖启动的棋力参考。相同课程函数可能产生不同对手分布，须同时报告实际对手比例、学习转移和计算成本。

A2C 已完成 90,000 局训练、14,400 局验证、1,200 局原始冻结测试。Random 黑 / 白的三种子胜率均值±样本标准差为 98.00%±1.00 pp / 97.67%±1.53 pp，Greedy 为 1.67%±2.89 pp / 0.33%±0.58 pp，表明对 Greedy 仍弱。完整种子 11 配对中，A2C 相对 DQN4 的 Random 黑 / 白胜率差为 +23 / +31 个百分点、Greedy 均为 0；未完成的 DQN4 种子保持空白，不作三种子配对结论。近似同容量、同课程机制并不构成严格等计算预算比较。

## 验证、选择与冻结测试

验证：AZ 在暖启动后先做一次第 0 局验证，训练中 DQN/A2C 每 1000 局、AZ 每 250 局，每对手每色 40 局（一次 160 局）。最终每对手每色 100 局（一次 400 局）。测试种子与验证种子分离，best.pt 只由验证集 greedy 平均 score 选择，最终测试不用于调参或选模型。网页 A2C 候选是 seed22 第 19,000 局的 best，验证 Greedy 平均 score=0.0125。

DQN 跨种子报告均值、样本标准差和配对差。单次胜率附 Wilson 95% 区间，score 不冒称 Wilson 胜率。算法间局数、搜索与计算成本不同，不视为严格预算公平的算法排名。

## 规则解释

同一策略/权重两边对弈降低双方模型不同的干扰，但颜色条件输入、网络学习偏置、固定搜索深度与开局分布仍可能影响结果。规则对照只能说明该固定策略与开局协议下的黑白胜率变化，不能证明 9×9 先手必胜或把全部差距归因于规则。

本轮选择可选黑方禁手方案；未实现开局交换。深浅搜索交叉对照可后续开展，本轮未计入已完成实验。禁手模式暂用于冻结评估，正式模型训练仍为 freestyle；因此禁手测试也包含规则分布变化，若需要最强禁手棋力，应另开 renju 训练目录。

## 中断与续训

检查点保存模型、EMA/target、Adam、replay、RNG、greedy RNG/课程健康窗口或历史池与计数器。AZ 每 10 局、DQN 每 250 局定期保存。半局中断保留上一完整检查点，续训会回退超出检查点的 CSV 行。

A2C 每 250 局等待全部在途棋局完成后保存完整屏障检查点。seed22 首次 CUDA 失败后从第 0 局检查点恢复，未减少预算。seed11 两个全 NUL 的 JSON 已备份，并以原 best 权重重做冻结测试、逐行核对原记录后恢复，见 [恢复审计](../runs/production/a2c4_seed11/artifact_recovery.json)。这 400 局仅用于完整性核验，不增加原始 1,200 局最终测试统计。

相同机器与软件固定种子便于重复，仍不能保证跨设备/版本逐局完全相同。Windows 笔记本休眠或断电会暂停或结束计算；恢复后重运行调度命令。不要同时运行两个写同一 output 的进程。
